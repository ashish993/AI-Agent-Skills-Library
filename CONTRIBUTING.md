# Contributing to AI Agent Skills Library

Thank you for adding a skill! Follow these steps.

## Steps

1. Fork this repository
2. Create a directory: `skills/<your-skill-slug>/`
3. Copy `template/SKILL_TEMPLATE.md` to `skills/<your-skill-slug>/SKILL.md`
4. Fill in every section
5. Add an entry to `skills.json`
6. Submit a pull request

## Naming Convention

- Slug: lowercase, hyphens, no spaces (e.g., `github-pr-review`)
- Title: Title Case (e.g., "GitHub PR Review")

## Quality Bar

- Description must be one clear sentence
- When to use / when NOT to use must be filled
- At least one working code example
- Input/output must be typed

## Skill Categories

```
developer-tools   security   data-etl   browser   research
monitoring        email      media      content    finance
```

Pick the closest category or propose a new one in your PR.

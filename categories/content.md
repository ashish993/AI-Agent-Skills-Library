# Content Skills

Skills for turning information into clear, audience-focused visual and written artifacts.

| Skill | Description |
|-------|-------------|
| [interactive-data-diagram-presentation](../skills/interactive-data-diagram-presentation/SKILL.md) | Turn supplied evidence into an interactive, self-contained HTML presentation with accessible inline SVG |

## Adding a Content Skill

Content skills should:
1. Preserve the meaning and provenance of supplied evidence
2. State assumptions, limitations, and unresolved questions visibly
3. Produce audience-ready artifacts with accessible, usable presentation
4. Include an example that demonstrates a practical output pattern

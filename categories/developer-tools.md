Skills for software development workflows.

| Skill | Description |
|-------|-------------|
| [github-pr-review](../skills/github-pr-review/SKILL.md) | Review a GitHub pull request |
| [web-search](../skills/web-search/SKILL.md) | Search the web for current info |

## Adding a Developer Tool Skill

Developer tool skills should:
1. Integrate with a specific API or CLI tool
2. Return structured output (not just raw text)
3. Handle auth via environment variables, not hardcoded values

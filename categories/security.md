# Security Skills

Skills for security scanning, auditing, and monitoring.

| Skill | Description |
|-------|-------------|
| [cve-scanner](../skills/cve-scanner/SKILL.md) | Scan packages for CVE vulnerabilities |

## Security Skill Requirements

Every security skill must:
1. Document which data it accesses
2. Never log or store credentials
3. Have a "When NOT to Use" section
4. Be reviewed by a maintainer with security background before merge
